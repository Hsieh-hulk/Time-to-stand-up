# 待辦清單

v1.0 範圍凍結:計時 → 強制休息 → 解鎖、智慧暫停、設定視窗、首次啟動畫面、主題、開機自動啟動、安裝程式。
以下項目**刻意延後**,要做時再個別評估,不要一次加入。

## 功能

- **程式排除清單**(原 M4):指定的程式在前景時(例如簡報、視訊會議、全螢幕遊戲)延後休息。
- **跳過 / 延後的進一步保護**(原 M5):休息前提示已可「延後 5/10/15 分」或「略過這次」,每個工作週期上限 2 次(休息完成或離開夠久才歸零)。尚未做:上限可調、系統匣入口、設定或結束是否需要密碼。目前系統匣的「設定…」「結束」只在工作狀態可用,沒有其他保護。
- **完整系統匣**(原 M6):顯示剩餘時間、暫停一段時間、開啟設定的快捷方式等。
- 再次啟動 exe 時直接打開設定視窗(目前只顯示「已經在執行中」的提示)。
- 設定視窗中調整智慧暫停開關(目前只能編輯 `config.json` 的 `smartPause`)。
